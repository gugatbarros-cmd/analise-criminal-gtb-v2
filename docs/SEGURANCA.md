# Segurança inicial

API e interface vinculadas a loopback. Sem credenciais embutidas, dados reais, Firebase ou chamada CAD. `.gitignore` exclui bases, planilhas, variáveis e logs. A interface informa que não há dados carregados. Não abrir o servidor para a rede antes de definir autenticação e perfis. Publicação web só de agregados aprovados.
