# Segurança inicial

API e interface vinculadas a loopback. Sem credenciais embutidas, Firebase ou chamada CAD. `.gitignore` exclui bases, planilhas reais, variáveis e logs; as planilhas versionadas em `fixtures/synthetic/` são artificiais. A API exige conta local e perfis de administrador, analista ou consulta. O banco e os arquivos brutos no disco ainda não têm criptografia específica: usar apenas dados sintéticos até a validação operacional. O executável local usa `%LOCALAPPDATA%\GTB2\data` por padrão; o ambiente `GTB_DATA_DIR` permite escolher outra pasta local. Não abrir o servidor para a rede. A prévia privada publica somente dados sintéticos.
