# Entradas necessárias para as próximas fases

1. Exemplos anonimizados e layout de seis fontes: ocorrências, MVI CAD, MVI NEAC, armas, drogas e guarnições. Confirmar se tentativas de homicídio e CVP têm fonte própria ou derivam de ocorrências.
2. Identificador único estável de ocorrência e vítima em cada fonte; regras para linhas sem identificador.
3. Definição oficial de MVI e casos de referência aprovados, inclusive diferenças entre CAD e NEAC.
4. Perfis, permissões e requisitos de autenticação no uso local e futuro uso multiusuário.
5. Ambiente autorizado para eventual hospedagem e sincronização, com restrição de R$ 0 e destino permitido para agregados.
6. Estratégia aprovada de exportação e restauração dos dados atuais do Firestore e de cada navegador antes de qualquer migração.

Nenhuma destas entradas é necessária para a tela inicial local. Elas são obrigatórias antes de declarar paridade ou usar dados operacionais.
