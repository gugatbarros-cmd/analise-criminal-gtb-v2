# Projeto GTB 2.0

- Manter execução local e custo de serviços em R$ 0.
- Usar apenas dados sintéticos em testes e arquivos versionados.
- Não acessar ou modificar o legado, Firebase ou CAD a partir deste projeto sem autorização específica.
- Não publicar dados reais no Git, GitHub Pages ou demonstrações. O usuário autorizou em 29/10/2026 a sincronização dos dados processados para consulta online autenticada, usando exclusivamente `sharedBases/gtb2-online` no Firebase Spark existente. Originais, contas locais e backups permanecem locais. Não alterar as bases do legado.
- Atualizar a versão do novo projeto ao alterar funcionalidades ou documentação.
- A cada entrega, atualizar `frontend/src/project-progress.json` e `docs/STATUS_IMPLEMENTACAO.md` com fases concluídas, percentual concluído e percentual restante. Marcar fase concluída apenas após validar todas as suas entregas.
